# DSH 记忆体架构

> 给 AI 助手（DSH / DeepSeek Harness）用的一套**可复刻的长期记忆系统**。
> 核心思想：**记得住的是标签，不是原文；过期的不删除，只不再加载。**

## 它解决什么问题

AI 助手每次会话都从零开始：不记得你是谁、不记得上次做到哪、不记得约定过什么。
把对话记录全塞进上下文 → token 爆炸；只存摘要 → 丢细节。

这套架构的做法是**分文件 + 按需加载 + 遗忘机制**：

| 问题 | 做法 |
|---|---|
| 记不住人 | 单开 `10-主人` 存"这个人是谁、在意什么、边界在哪" |
| 记不住事 | 单开 `20-项目` 存**当前状态**（在办什么、到哪一步） |
| 记不住规矩 | `30-约定` 存红线；`40-教训` 存踩过的坑 |
| 越写越乱 | `00-索引` 只写一句话地图，细节在各自文件 |
| 上下文爆炸 | **开局只读索引**，其余按需 |
| 舍不得删又用不着 | `90-遗忘` **不删除，只不再加载** |

---

## 特点

- **纯文件，无数据库**：Markdown + CSV，坏了能手改，随时能拷走
- **token 可控**：常加载约 6k tokens，全量约 2 万，遗忘区 1.5 万永不主动读
- **不会丢东西**：失效条目进遗忘区（保留原文），不物理删除
- **可回滚**：每次改架构打快照 zip，解压即恢复
- **四重备份**：本地 → 同盘副本 → 异盘 → 云笔记
- **自带 skill**：`SKILL.md` 让另一个 DSH 照着就能复刻

## 文件结构

```
memory/
├── 00-索引.md            记忆地图（每条一句话 + 指向文件）  ← 开局必读
├── 10-主人.md            这个人是谁：档案、习惯、偏好、边界
├── 20-项目与工作区.md     当前状态：机器、项目、在办的事
├── 30-约定.md            长期约定与红线
├── 40-教训.md            踩过的坑与正确做法
├── 50-时间线.md          大事记（只记里程碑）
└── 90-遗忘.md            失效条目的原文归档（不加载）
```

配套：`AGENTS.md`（人格本体，放在 `~/.dsh/` 下，与 memory 同级）

## 快速开始

### 方式一：让 DSH 自己搭（推荐）

把 `SKILL.md` 放到 `~/.dsh/skills/dsh-memory/`，然后用 DSH 说：

```
帮我初始化记忆体架构
```

它会按 SKILL.md 建目录、写模板、生成第一版索引。

### 方式二：手工复制

```bash
mkdir -p ~/.dsh/memory
cp templates/*.md ~/.dsh/memory/
```

然后把 `00-索引.md` 里的占位内容替换成你自己的第一条记忆。

## 把已有会话导入成记忆（V1.2）

**适用**：你的 DSH 只有会话记录、还没有记忆架构。

```bash
python tools/context_import.py --list                     # 列出所有会话
python tools/context_import.py --session <id前缀> --out preview   # 导一个
python tools/context_import.py --all --out preview               # 导全部
```

**它做什么**：读 `~/.dsh/sessions/**/session.v4.jsonl.zstd` → 去噪（去掉 reasoning、工具调用、
系统注入、渠道尾巴）→ 按记忆架构分类 → 生成草稿到 `--out` 目录 + 导入报告。

**它不做什么**：
- ❌ 不改写原会话（只读）
- ❌ 不写 `~/.dsh/memory/`（**必须先看预览再合并**）
- ❌ 不代替你整理（分类是启发式，草稿必须人工删减）

> 实测：16 MB 会话 / 1312 条有效事件 → 约 70 秒 → 6 个草稿文件。
> 详见 [docs/记忆体架构-V1.2.md](docs/记忆体架构-V1.2.md)

## 设计取舍

| 选择 | 原因 |
|---|---|
| 不用向量库 | 关键词 + 标签 + 时间衰减够用，省依赖省算力 |
| 不用数据库 | Markdown 人可读、git 可 diff、坏了能手改 |
| 索引只写一句话 | 索引涨一句，每次开局都多付一次 token |
| 遗忘区不删原文 | 「这些都是回忆」——省 token 不等于丢信息 |
| 月度体检而非自动化 | 判断"该不该留"需要人（或 agent）看，脚本只做筛查 |
